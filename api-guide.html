REST-API Guide

Anleitung zur Erstellung und Nutzung eines GitHub Personal Access Tokens für Repository-Analysen.

Kurzfassung: Für öffentliche Repositories genügt ein Token mit Leserechten. Der Token wird lokal im Browser verwendet und nicht in das Repository geschrieben.

1. GitHub Token erstellen

GitHub Settings öffnen

GitHub öffnen, rechts oben auf das Profilbild klicken und Settings auswählen.

Developer settings

Developer settings öffnen und danach Personal access tokens auswählen.

Fine-grained Token

Fine-grained tokens wählen und einen neuen Token mit minimal notwendigen Leserechten erstellen.

Token kopieren

Der Token wird nur einmal angezeigt. Danach kann er im Analyzer gespeichert werden.

Verwendete API-Endpunkte

GET /repos/{owner}/{repo}

Basisdaten wie Stars, Forks, Beschreibung, Sprache, Lizenz und Alter.

GET /repos/{owner}/{repo}/stats/commit_activity

Commit-Aktivität der letzten Wochen.

GET /repos/{owner}/{repo}/issues?state=all&per_page=100

Issue-Schließungsrate, Schließzeit und Engagement.

GET /repos/{owner}/{repo}/releases?per_page=20

Release-Frequenz und Regelmäßigkeit.
